Reminder

• UTF-8 CSV only (Excel: File --> Save as --> "CSV UTF-8"). Never rename an .xlsx to .csv.

• Keep the header row and column order: Date / period, Place / geography, What happened, Explanation, Thematic Categorisation. "What happened" is required.

• Quote cells containing , ; or line breaks with "…" (double a literal " as "").

• Be as precise as possible with Place / geography (city, region, country) — it is geocoded automatically. "Global", "International", "N/A"… = entry listed without a map point.

• Thematic Categorisation: free text; new values automatically become new map filters. Separate several categories with ;. 

• No Lat/Lon columns needed (we can add them in the future if needed).

• Upload ONE csv here, replacing the previous file (not next to it).

• After upload, wait a few minutes (sync + deploy), then check /hr-genealogies/.
